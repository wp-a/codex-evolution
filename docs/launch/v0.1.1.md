# Codex Evolution v0.1.1

Codex Evolution turns local Codex history into a workspace for reviewing prompting habits, checking source evidence, auditing project instructions, and preparing reusable methods.

This first public release includes:

- A macOS-inspired interface with a first-use guide, grouped navigation, light/dark themes and responsive layouts.
- Monthly phrase heatmaps, source-linked messages, retrospective reports and aggregate-only exports.
- Conservative reviews of AGENTS.md, Skill instructions and project plans, with source citations and proposed edits.
- Five editable prompt templates and evidence-supported Skill drafts.
- Chinese and English documentation, eight promotional images and ready-to-use launch copy.

## Try the synthetic demo

```bash
git clone https://github.com/wp-a/codex-evolution.git
cd codex-evolution
python3 -m codex_evolution demo --open
```

Python 3.10+ is required. Running from source has no third-party runtime dependencies. The interface is currently in Chinese. Demo mode uses synthetic data and does not scan your history.

## Downloads

- **Source ZIP:** runnable source, documentation, tests and image assets.
- **Python wheel:** install locally with `python3 -m pip install ./codex_evolution-0.1.1-py3-none-any.whl`.
- **Media kit ZIP:** eight PNGs, editable source, an offline gallery and launch copy.

## Scope and verification

Local tests cover 80 unit/integration cases. The interface was checked in real Chrome, including evidence navigation, import/export actions, light/dark themes and mobile widths. Packaging was built and installed in an isolated Python environment. See [QA](https://github.com/wp-a/codex-evolution/blob/main/docs/QA.md) for the detailed evidence and limits.

Local records stay on your machine by default. Optional model interpretation requires separate configuration, a material preview and explicit consent. No paid live model inference was used in these checks. The statistics describe recorded signals; they do not measure personal ability or prove task success.
